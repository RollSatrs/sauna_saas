# Документация проекта

Два документа для команды. **Источник правды — HTML.** Word собирается из него скриптом,
руками .docx не правим: иначе версии разойдутся и через месяц никто не поймёт, какая актуальна.

| Документ | Исходник | Word | Кому |
|---|---|---|---|
| Техническое задание, MVP | `tz-mvp.html` | `ТЗ MVP - SaaS для бань и саун.docx` | разработчикам |
| То же простыми словами | `tz-prostoe.html` | `ТЗ простыми словами.docx` | владельцам, не-техническим участникам |

Веб-версии (те же документы, читаются с телефона):
- ТЗ — https://claude.ai/code/artifact/b1a7810d-93f7-4fef-91aa-11b3d50f19f9
- Простыми словами — https://claude.ai/code/artifact/5cd9f112-a48d-43f7-8961-1b4c454e5fae

## Пересобрать Word после правок

Один раз:

```
python3 -m venv .venv
.venv/bin/pip install -r docs/requirements.txt
```

Дальше после каждой правки HTML:

```
.venv/bin/python docs/build-docx.py
```

Скрипт соберёт оба файла. Чтобы собрать один: `.venv/bin/python docs/build-docx.py docs/tz-mvp.html "docs/имя.docx"`.

## Что получается в Word

Стили заголовков (работает панель навигации и автосборка оглавления), повтор шапки таблиц
при переносе на страницу, цветные врезки для решений и предупреждений, нумерация страниц.
Шрифты — Calibri / Georgia / Consolas, они есть в стандартной поставке Office.

## archive/

Версии .docx, собранные до объединения сборки в один скрипт. Не редактировать, нужны только
на случай, если в них было что-то, чего нет в текущих. Можно удалить, когда убедитесь, что не нужны.
